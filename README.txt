RICK KOCH — MARKETING PORTFOLIO

QUICK START
1. Extract this ZIP.
2. Open index.html in your browser to preview the page.
3. Upload index.html, style.css, and the entire assets folder to the web folder served by your Strato domain, or to a portfolio subfolder there. Keep this structure unchanged.
4. Open the resulting HTTPS address, check the images and contact links, and place that address in the resume.

No build, installation, database, external fonts, or JavaScript is required.
The page can be used at the domain root or in a subfolder.
The exact Strato upload location depends on the domain's configured web directory.
Do not replace an existing site's index.html unless you intend to replace its homepage. A separate portfolio subfolder avoids that.
